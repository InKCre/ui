# 内容阅读

`InkContentReader` 接受 `content` 字符串和明确的 `format="html"` 或 `format="markdown"`。Markdown 按 GFM 呈现表格、只读任务列表、删除线和自动链接，原文由调用方保留；纯文本应使用文字容器。

组件在隔离的 iframe 中显示净化后的内容。脚本、样式、表单和嵌入页面不执行，媒体资源不自动加载；图片保留说明和可用的 HTTP(S) 引用。HTTP(S) 链接经点击在新窗口打开且不传递 referrer，页内锚点保留。没有可信来源地址时，相对链接不猜目标。组件不接收 Block、resolver 或来源对象，也不保存或改写内容。

Story 对照标准 HTML 的标题、表格、代码空白与链接，以及相同阅读规则下的 GFM。检查窄容器中的长代码可横向滚动，iframe 随正文增高；检查恶意脚本和图片请求均未发生。
