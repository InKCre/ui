# inkImage

InkImage 用原生按钮展示缩略图，Enter/Space 或点击打开全屏预览；名称优先使用 alt，其次是 title。请提供描述图片用途的 alt。

`v-model:expanded` 控制预览，省略时内部管理状态。预览由 InkScrim 提供模态、Escape、关闭按钮和焦点恢复；点击图片区的空白也会关闭，点击图片、说明或扩展内容不会误关闭。expand、close 反映用户打开和关闭动作；图片加载失败发出带 error 与 src 的载荷。

thumbnail、expanded-header、expanded-footer 可以补充内容，但缩略图槽内部不要嵌套另一个按钮。

“Custom Thumbnail Slot”在缩略图下方持续显示查看提示，可用键盘打开；“With Expanded Footer”提供实际 SVG 文件的下载链接。标题、提示和下载链接各自使用有明确前景配对的底板，在浅深主题和图片背景上保持可读。

预览默认适应可用图片区，保留比例且不放大小图片。滚轮围绕指针位置连续缩放，触屏双指同时缩放和平移，放大后可直接拖动查看各处；抬起一指后，剩余一指可以继续拖动。图片较小的轴保持居中，超出视口的轴可拖至两端。缩放从适应窗口到 800%，不会因超过原始像素尺寸而停在 100%；放大已有像素不新增图片请求。

操作区提供缩小、当前比例、放大、适应窗口与 100% 原尺寸。双击 / 双点在全图和细节比例间切换，按钮与键盘缩放以当前视口中心为锚点。图片区可以通过 Tab 获得焦点：+ / − 缩放，方向键和 PageUp / PageDown 浏览，Home / End 到边角，0 返回全图，1 原尺寸。打开或更换 src 恢复全图；窗口改变时，全图继续适应，已放大视图尽量保留中心正在查看的内容。

操作区保持固定，不透明底板隔开预览与原页面。标题和扩展页眉 / 页脚与图片分别布局，高度受限但内容不截断，可在各自区域滚动；标题使用说明文字层级，不与图片争夺注意。预览等待加载时显示进度提示，失败后显示可读的错误状态并保留关闭入口。

“Large Image Detail”提供大尺寸、细小文字与边角内容；先定位一处细节，连续放大到超过 100%，拖到另一处，再回到全图。“Tall Image With Long Caption”用于在窄屏检查长图和长说明各自可达，说明滚动不得带动图片。双指操作应额外核对偏心捏合时内容不跳离手指、两指中点移动能平移、抬一指后继续拖动，以及取消手势后仍可操作。“Controlled Preview And Source Change”可从外部按钮打开，缩放后通过页眉切换图片，核对复位、受控关闭及焦点返回。“Unavailable Image”演示解码失败后的反馈。
