# inkImage

InkImage 用原生按钮展示缩略图，Enter/Space 或点击打开全屏预览；名称优先使用 alt，其次是 title。请提供描述图片用途的 alt。

`v-model:expanded` 控制预览，省略时内部管理状态。预览由 InkScrim 提供模态、Escape、关闭按钮和焦点恢复；点击图片区的空白也会关闭，点击图片、说明或扩展内容不会误关闭。expand、close 反映用户打开和关闭动作；图片加载失败发出带 error 与 src 的载荷。

thumbnail、expanded-header、expanded-footer 可以补充内容，但缩略图槽内部不要嵌套另一个按钮。

“Custom Thumbnail Slot”在缩略图下方持续显示查看提示，可用键盘打开；“With Expanded Footer”提供实际 SVG 文件的下载链接。标题、提示和下载链接各自使用有明确前景配对的底板，在浅深主题和图片背景上保持可读。

预览默认适应可用图片区，保留比例且不放大小图片。“100%”使用图片的原始尺寸，便于读取细节；图片超出可用区域时使用滚轮、滚动条、触屏滑动或键盘方向键 / PageDown 浏览。图片区可以通过 Tab 获得焦点。滚轮用于滚动，不实现连续缩放、鼠标拖动或自定义捏合手势。每次打开或更换 src 都恢复适应模式，切换模式后从图片左上方开始阅读。

操作区保持固定，不透明底板隔开预览与原页面。标题和扩展页眉 / 页脚与图片分别布局，高度受限但内容不截断，可在各自区域滚动；标题使用说明文字层级，不与图片争夺注意。预览等待加载时显示进度提示，失败后显示可读的错误状态并保留关闭入口。

“Large Image Detail”提供大尺寸、细小文字与边角内容；“Tall Image With Long Caption”用于在窄屏检查长图和长说明的可达性；“Controlled Preview And Source Change”可从外部按钮打开，进入原尺寸后通过页眉切换图片，核对模式复位、受控关闭及焦点返回。“Unavailable Image”演示解码失败后的反馈。实际验收应完成打开、读取边角细节、返回全图和关闭这一过程。
