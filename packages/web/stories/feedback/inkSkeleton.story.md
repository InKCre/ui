# inkSkeleton

InkSkeleton 是已知内容结构的单块占位。默认占满容器宽度，高度为一行文字的 1em；宿主用普通 class/style 指定宽高，组合标题、摘要或属性行。它不提供列表模板、请求状态或假的可点击操作。

占位采用浅深主题的低对比中性色与直角轮廓，缓慢改变透明度；prefers-reduced-motion 下保持静止。每块固定 aria-hidden，宿主为整个等待区域提供一次状态说明，加载结束后替换骨架。结构未知的图谱或内容预览使用 InkLoading 默认三方块；已有内容刷新应保留内容，并在刷新动作旁显示等待。

Story 的 Known list structure 展示三个条目。检查浅深主题、窄容器、20px 根字号和减少动态效果偏好，确保骨架不溢出且辅助技术只获得一次列表加载状态。
